# Discussing a question with other models

Use this when the user asks you to discuss, debate, or cross-check a question
with other models. The point is to find where independent readers disagree,
because agreement between models that saw each other's answers proves little.

Commands: guide section "Hand work to another session", passing the agent to
use.

## Round 1: independent answers

Delegate the same brief to each model. Give every participant:

- the question, and the material to read, by path;
- no hint of your own answer and no answer from another participant;
- the instruction to read only: no file edits, no commits;
- the instruction to separate what it verified from what it infers, and to
  write "unconfirmed" where it found no evidence;
- the answer format: one recommendation, the reasons, the claim it is most
  sure of, and the claim it most wants challenged.

Write your own answer before you read theirs, so you are a participant too.

## Round 2: only the disagreements

Compare the answers. Where all agree, stop. For each point where they differ,
send each participant the opposing position, quoted, and ask one thing: keep
your position or move, and why. Use a message to the existing session so it
keeps its context (guide section "Talk to a session").

Skip this round when round 1 shows no real disagreement.

## Round 3: settle against evidence

Decide each remaining point by checking the primary source yourself (the
code, the document, a measurement), not by counting votes. A point nobody can
support with evidence stays "unconfirmed" in your report.

## Report

Give the user a table: the point, each participant's position, the evidence,
and your verdict. Then your recommendation. Say which points were unanimous
from the start and which stayed unconfirmed.
