# Splitting a session by topic

Use this when a session has drifted across several unrelated topics, when the
user asks to move a topic into its own session, or when a title no longer
says what the session is about.

## Split

1. Read the conversation and list its topics with the point where each one
   starts (guide section "Watch another session").
2. Keep the topic the session is still working on where it is. Move only
   topics that are separable and still open. A topic that is finished needs
   no session.
3. For each topic you move, start a session whose brief says which session
   and which part of it the topic comes from, and asks it to read that part
   and open with a summary of 5 to 10 lines: what was decided, what was
   produced and where, and what is still open. Starting it as a delegated
   session gives it a digest of the original and wakes you with that summary
   (guide section "Hand work to another session").
4. Tell the user which sessions now hold which topics, by title.

## Retitle

A title should name the outcome the session is working toward, in the user's
language, in a few words. Rename a session when its work has changed, and
after a split so that the original no longer claims the topics that left
(guide section "Rename a session").

When asked to retitle many sessions, read the latest exchange of each one
first. A title guessed from the old title repeats its mistake.
