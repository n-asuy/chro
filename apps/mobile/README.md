# Chro Mobile

Bare React Native mobile app backed by a Rust native crate.

## Commands

- `bun run dev`: start Metro on `8090` by default
- `bun run setup`: install workspace dependencies and iOS pods
- `bun run setup:ios`: install iOS pods only
- `bun run ios`: run the iOS native app
- `bun run android`: run the Android native app
- `bun run typecheck`: type-check TypeScript
- `bun run lint`: run Biome checks
- `bun run test:rust`: test the Rust crate
- `bun run build:rust`: build the Rust crate for the host target

## Structure

- `android/`: native Android project generated by React Native CLI
- `ios/`: native iOS project generated by React Native CLI
- `src/native/specs/NativeChro.ts`: TurboModule spec for codegen
- `src/native/chro-native.ts`: JS boundary with fallback until the platform bridge is linked
- `native/`: Rust crate exported as `staticlib` / `cdylib` / `rlib`

Set `CHRO_MOBILE_PORT` to override the Metro port:

```sh
CHRO_MOBILE_PORT=8091 bun run ios
```

`bun run ios` checks CocoaPods lockfiles first and runs `setup:ios` automatically
when the Pods sandbox is out of sync.
It also starts Metro on the configured port before launching the app.
